# Hisaab Bolo — build plan

Build contract: `docs/ARCHITECTURE.md`, `docs/paytm/PAYTM_INTEGRATION.md`, UI from `docs/pitch-deck.pdf` slides 4–6.

Each milestone is done only when: its pytest + Playwright tests pass, a fresh tester agent (spec + code only) finds no failures after driving the UI in Chrome, screenshots are saved in `evidence/mN/`, and the work is committed.

## Local setup decisions

- Local Supabase (Docker, ports 554xx; `supabase/config.toml`) with an ES256 signing key, so JWT verification matches the hosted project's ES256 JWKS. The hosted project is empty and needs its database password to receive migrations (`supabase db push --db-url ...`).
- `.env` holds the real third-party keys. `.env.local` (generated by `scripts/local-env.sh`) overrides the Supabase settings for the local stack.
- API: FastAPI on :8000 (`api/`). Web: Next.js 16 on :3000 (`web/`).
- `PAYTM_MODE=mock`; `EMAIL_MODE=resend|log` (tests use `log`).

- [ ] **M1 Schema + seed**: migrations (tables, `app_now()`, views, RLS, realtime publication, storage bucket), seed script (Gupta Kirana Store, ~40 payers, 90 days, ~8k rows, Ram, Sharma Traders, a lapsed regular, open invoices), demo merchant login.

- [ ] **M5 Recurring + clock**: recurring schedules, `/jobs/tick` (dues, overdue reminders, status polling, AI descriptions, alerts), `/admin/clock`, demo clock UI, cron service config.
- [ ] **M6 Voice agent**: typed tools, Claude tool loop (Haiku → Sonnet retry), number guard, components, pending actions + confirm, Sarvam STT/TTS, Ask Hisaab UI with push-to-talk and text fallback.
